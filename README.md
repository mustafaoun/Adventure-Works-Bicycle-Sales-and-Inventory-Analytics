# Adventure Works Bicycle Sales and Inventory Analytics

Power BI portfolio project exploring bicycle sales, profitability, inventory, and customer behavior for a simulated business. Developed as part of my Power BI learning work.

## Review the available work

- [Download the five-page report](The%20Report.pdf).
- [Watch the dashboard walkthrough](2025-09-24%2020-00-38.mp4).

The PDF provides a static snapshot; the video demonstrates the report experience. Download the video if GitHub does not preview it.

## Analysis approach

The original project work used historical AdventureWorks sales data, a star-schema model, and DAX measures for sales, profit, margins, time comparisons, and scenario analysis. The walkthrough and report are the evidence currently provided in this repository.

## Reproducibility and delivery status

The editable `.pbix`, source CSVs, exported DAX definitions, model diagram, and a public Power BI Service link are **not included**. This repository therefore presents report outputs rather than a fully reproducible Power BI build. The committed PDF contains five pages; earlier descriptions of a seven-page deliverable were inconsistent with this export.

Scheduled refresh, alerts, simulated exchange-rate inputs, and historical publication cannot be verified from a PDF alone. They should not be interpreted as evidence of a currently live service. Findings are exploratory results on a sample dataset, not measured commercial impact.
